## Apa itu Metered Billing dan Kenapa Kamu Harus Peduli?

Juni 1, 2026. Hari itu GitHub resmi migrasiin **semua** user Copilot Pro/Pro+ ke **usage-based billing**. Dulu? Bayar $10/bulan (Pro) atau $19/bulan (Pro+), pakai sepuasnya. Sekarang? Bayar per token. Tiap kali lu nanya ke AI, tiap kali AI nulis kode, tiap kali AI baca repo lu — **semua dihitung per token**.

Hasilnya? Banyak developer lapor tagihan melonjak gila:

| Scenario | Dulu (Flat) | Sekarang (Metered) |
|----------|-------------|---------------------|
| Dev casual, 20 prompt/hari | $10/bln | ~$15-25/bln |
| Dev aktif, 100 prompt/hari + agentic | $19/bln | **$200-400/bln** |
| Power user, autonomous agents jalan 24/7 | $19/bln | **$500-750+/bln** |

> **Fakta Pahit:** Satu developer di Reddit lapor tagihan Copilot naik dari **$29 jadi $752** dalam sebulan. Dia cuma pake agentic feature buat refactor kode legacy 3 hari. Tiga hari = $700+. Gaji junior developer sebulan di Indo bisa kurang dari itu.

## Kenapa Metered Billing Bikin Panik Para Pemula?

### 1. **Tidak Ada "Unlimited" Lagi — Setiap Ketik Dihitung**

Dulu lu bisa `Tab` spam suggestion sepuasnya. Sekarang? Tiap suggestion yang lu accept = token output. Tiap kali lu tanya "jelasin fungsi ini" = token input + output. Tiap kali agent baca 50 file di repo = **massive token input**.

```markdown
# Contoh kasus nyata:
- Prompt: "Refactor todo app jadi pakai React Query" (50 token input)
- AI baca 15 file context (15,000 token input)
- AI nulis ulang 8 file (8,000 token output)
- Total: ~23,050 token = ~$0.23 (pakai model premium)

Kalo lu lakuin 10x sehari = $2.30/hari = $69/bulan.
Cuma buat SATU task. Belum hitung trial-error, retry, follow-up prompt.
```

### 2. **Agentic Features = Money Burner Tersembunyi**

Fitur keren kayak "autonomous agent baca repo, planning, edit multi-file, jalanin test, bikin PR" — **ini yang paling boros token**. Agent butuh konteks penuh repo (ratusan ribu token), lalu iterasi berkali-kali.

> *\"Agentic coding itu kayak nyuruh asisten pinter tapi boros listrik. Dia kerja cepet, tapi tagihan listrik lo yang nangis.\"*

### 3. **Tidak Ada Hard Cap Otomatis (Buat Banyakan Plan)**

GitHub Copilot **tidak** otomatis stop kalau tagihan melebihi batas tertentu. Lu harus manual set budget alert di billing settings. Banyak pemula gak tau ini sampe tagihan datang.

## Bandingin: Flat vs Metered — Mana Lebih Cocok Buat Lu?

| Faktor | Flat Rate (Subscription) | Metered (Usage-Based) |
|--------|--------------------------|------------------------|
| **Predictability** | ✅ Fix tiap bulan | ❌ Variabel, bisa melonjak |
| **Cost control** | ✅ Bisa budgeting | ❌ Harus monitor terus |
| **Heavy usage** | ✅ Murah kalau pakai banyak | ❌ Mahal banget kalau heavy user |
| **Light usage** | ❌ Mahal kalau jarang pakai | ✅ Bayar secukupnya |
| **Psychological** | ✅ Tenang, "udah bayar" | ❌ Anxiety tiap pakai AI |

### Kapan Flat Rate Lebih Baik?
- Lu **pelajar/pemula** yang belajar ngoding pake AI tiap hari
- Lu **freelancer** dengan project besar, butuh AI 8 jam sehari
- Lu **tim startup** yang pakai agentic features intensif

### Kapan Metered Lebih Baik?
- Lu **hobiis** cuma pakai AI seminggu sekali
- Lu **sudah mahir** cuma butuh AI buat boilerplate sebentar
- Lu **perusahaan** yang mau chargeback ke client per project

## 5 Strategi Biar Gak Kena Bill Shock (Buat Pemula)

### 1. **Set Budget Alert SEKARANG** (Bukan Nanti)

Masuk ke GitHub Settings → Billing → Spending limit → Set alert di $10, $25, $50. **Jangan skip langkah ini.** Itu gratis dan bisa selamatkan dompet lu.

```bash
# Caranya:
1. Buka github.com/settings/billing
2. Scroll ke "Spending limit"
3. Set "Monthly spending limit" = $20 (atau sesuai budget)
4. Centang "Notify me when spending reaches 50%, 75%, 90%"
5. Save
```

### 2. **Pake Model Lebih Murah Buat Hal Kecil**

Gak semua task butuh model premium (GPT-4o, Claude 3.5 Sonnet). Buat:
- **Explain code / baca docs** → Model kecil/cheaper (GPT-4o-mini, Haiku)
- **Generate boilerplate** → Model medium
- **Complex refactor / architecture** → Model premium

> **Pro Tip:** Di Cursor/VS Code, lu bisa pilih model per chat. Jangan selalu pakai "Auto" (yang default ke paling mahal).

### 3. **Kurangi Konteks yang Dikirim ke AI**

Token input **paling mahal** kalau lu kirim seluruh repo. Tips:
- **Jangan** `@codebase` atau `@repo` kalau gak perlu
- **Hanya** tag file yang relevan: `@src/components/Button.tsx`
- **Gunakan** `.cursorignore` / `.gitignore` buat exclude folder `node_modules`, `dist`, `build`, log files

```markdown
# .cursorignore contoh:
node_modules/
dist/
build/
*.log
.env
coverage/
.next/
```

### 4. **Batch Prompt, Jangan Piecemeal**

Bandingin:
- ❌ **Piecemeal (boros):** "Buat Button" → "Tambah loading state" → "Tambah disabled" → "Fix typescript error" = 4x API call
- ✅ **Batch (hemat):** "Buat Button component dengan: loading state, disabled prop, TypeScript strict, pakai Tailwind, aksesibel" = 1x API call

### 5. **Punya "AI-Free Days" / Timeboxing**

Set timer: "Maksimal 1 jam pakai AI hari ini." Atau tentukan hari tertentu gak pakai AI sama sekali. Ini:
- Ngasah skill **manual coding** (penting buat interview!)
- Mencegah **dependency** berlebihan ke AI
- **Hemat uang** otomatis

## Alternatif Gratis/Murah Buat Pelajar & Junior Dev

| Tool | Harga | Kelebihan | Kekurangan |
|------|-------|-----------|------------|
| **GitHub Copilot Free** | $0/bln | 2000 completions/bln, 50 chat/bln | Limit ketat, no agentic |
| **Cursor Free** | $0/bln | 2000 completions, 50 slow premium requests | Slow request queue |
| **Codeium/Windsurf** | $0/bln | Unlimited completions (personal) | No agentic, model terbatas |
| **Continue.dev (Local)** | $0 + hardware | Pakai model lokal (Ollama), zero cost | Butuh GPU/ram besar, setup ribet |
| **Cline (VS Code Extension)** | $0 + API key | Bawa API key sendiri, full control | Harus kelola API key & billing sendiri |

> **Rekomendasi Gue Buat Pemula:** Mulai dengan **Codeium/Windsurf Free** + **GitHub Copilot Free**. Cukup buat belajar. Upgrade ke paid **hanya kalau** sudah kerja dan butuh agentic features.

## Mental Model: AI Adalah "Junior Developer Berbayar", Bukan "Senior Gratis"

Banyak pemula salah kaprah: *"AI nulis kode, berarti gue gak perlu belajar."*

**Salah besar.** AI itu kayak **magang junior yang cepet tapi longgar**. Dia:
- Nulis cepet tapi sering hallucinate
- Gak paham business logic lu
- Gak punya accountability (kalo bug, dia gak yang di-reprimand)
- **Mahal** kalau dia kerja lama (metered billing)

> *\"Bayar AI $500/bln biar nulis kode yang lu gak paham = investasi bodoh. Bayar $0 belajar ngerti kode sendiri = investasi seumur hidup.\"*

## Penutup: Jadi Siapa yang Untung? Lu atau Perusahaan AI?

Perusahaan AI (GitHub, Anthropic, Cursor, Google) **pasti untung** — mereka jual token. Siapa yang rugi? **Developer yang gak punya strategi.**

Kalo lu pemula, **jangan biar FOMO bikin lu bayar mahal untuk fitur yang lu gak butuh.** Belajar ngoding pake AI gratis dulu. Pahami basic. Bangun portfolio. Dapet kerja. **Baru** lu upgrade tool kalau gaji udah nampung.

> **Action Item:** Buka billing settings sekarang. Set limit $15/bulan. Kalau kelebihan, berarti waktunya evaluasi workflow — bukan waktunya tambah budget.
